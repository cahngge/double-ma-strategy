# 双均线策略量化回测系统

## 项目简介
本项目基于 Python 实现了经典的双均线交易策略，
对工商银行（601398）2021-2025 年的历史数据进行回测。

## 策略逻辑
- 金叉买入：5日均线上穿20日均线
- 死叉卖出：5日均线下穿20日均线

## 回测结果
| 指标 | 结果 |
|------|------|
| 初始资金 | 100,000 元 |
| 最终资产 | 111,691.17 元 |
| 累计收益率 | 11.69% |
| 最大回撤 | -23.65% |
| 回撤发生时间 | 2023-09-01 |

## 技术栈
- Python 3
- pandas（数据处理）
- matplotlib（可视化）
- akshare（数据获取）

## 项目结构
- `double_ma_strategy.ipynb`：完整代码与回测过程
